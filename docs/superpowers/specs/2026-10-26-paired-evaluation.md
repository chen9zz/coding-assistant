# Demo Agent / RAG 对照评估

用户已授权按推荐实施，不再增加设计确认轮次。

目标：复用生产 Agent Loop、网关和固定验收，比较相同 fixture 的 RAG 开关；保留每个失败、暂停、错误和人工备注。提供 JSON / Markdown 报告，不新增服务或数据库依赖。

范围：24 个固定词法检索问题；3 个固定修复任务，每任务每轮运行两个独立工作区。默认 scripted 合约评估，可显式配置真实 HTTP provider。相同源仓库 HEAD、任务、命令、模型配置、步数/时间预算，交替组顺序。脚本模式不证明模型收益，在线小样本也不能宣称普遍修复率。

安全：只执行内置可信 fixture，不接受外部任意仓库/命令；使用原工具注册和权限网关；不自动审批、不自动重试失败；模型配置只读取 provider，不连接额外 MCP/Skills/MySQL。密钥只从环境读取。原始状态在私有工作目录，报告不导出模型正文和异常正文。

方案：采用现有 Python 评估框架与 JSON/Markdown 报告；暂不引入评估 SaaS、向量库或新前端。人工备注另行追加、不能改写原始成绩；审批等待和审批决定分开记录。默认运行结束保留所有分母，出错后继续其他实验。
