# Agent / RAG 对照评估（Demo）

`forgepilot eval-compare` 对内置可信 fixture 运行 RAG 开启/关闭实验。复用生产 Agent Loop、权限网关、worktree、固定命令与宿主验收，不新增服务或自动审批。默认是离线脚本合约测试；显式 `--config` 才调用配置的模型 API。

## 运行

```bash
# 在已安装项目的环境中；输出目录必须不存在
forgepilot eval-compare --workspace /private/tmp/forgepilot-compare-001

# 真实模型：沿用安全注入进程环境的 API Key；不要写进命令、配置或聊天
forgepilot eval-compare --workspace /private/tmp/forgepilot-compare-online-001 \
  --config /absolute/path/to/assistant.toml --repetitions 1
```

在线配置仅使用 provider；不启用该配置中的 MCP、Skills、MySQL，防止其他工具/外部状态混淆 RAG 开关对照。状态使用专用本地 SQLite，RAG 缓存和工件都在私有评估目录。每轮 3 个任务 × 2 组；最多 3 轮。在线模式产生供应商费用，每个任务限制 24 步、300 秒、128000 字符上下文；独立隐藏验收另限 120 秒，不自动重试。

## 两类指标

**检索微型基准**：3 个内置小仓库各 8 个固定问题，共 24 题，覆盖标识符、表达式、英文改写、中文词组。标准答案是目标源码文件。关闭组调用现有 ripgrep search，查询词转义后作 OR 匹配，按路径/数值行号排序取前 5 条；开启组调用现有 FTS5/BM25，取前 5 个代码块。

- `hit_at_5`：前 5 个结果中是否有引用有效的目标文件，平均值不是多相关片段 Recall。
- `mrr`：第一个有效目标文件结果的排名倒数；未命中、异常、未运行均为 0。
- `citation_accuracy`：返回引用中内容、行号和文件 SHA-256 均匹配的比例；无结果为 null，不能算 100%。ripgrep 基线由宿主包装行引用，RAG 使用工具原生引用。
- 保留每题状态、耗时、截断及异常类型。全部题目预登记，失败不从分母移除。首个 RAG 请求包含索引构建开销，耗时不是纯查询性能。

两组返回单位不同（行/块），且样本极小，排序指标只用于诊断，不构成公平的大规模检索排行榜。当前不含 embedding、语义召回或跨文件推理题集。

**Agent 修复对照**：同一任务的两组使用同一个源 HEAD、问题和隐藏测试，各自建立新 worktree、数据库及索引。组顺序按任务/轮次交替，记录基线、fixture/问题摘要及预算。两组均能使用已有读取、搜索、映射工具，唯一新增工具差异为 `rag_search`。离线脚本两组使用相同预设补丁，区别是第一步检索；因此脚本成功率只能证明流程，不能证明 RAG 改善模型修复。

`resolved` 同时要求生产任务成功、改动路径符合要求、预期隐藏测试实际完成且通过。隐藏测试在 Agent 执行结束后安装；独立验收检查新生成 JUnit 中的确切测试身份，拒绝空报告、跳过、失败、缺失测试和进程提前 exit(0)。这仍是可信仓库 Demo，不是抗恶意候选代码的 OS 沙箱。

## 失败、审批和人工介入

- 每个计划中的 attempt 先写入报告，再执行。失败、等待审批、异常、未运行都保留，全部计入成功率分母。
- 每轮新建记录，不覆盖上一次失败。中断时报告 `complete=false`，正在执行项保留 RUNNING，其含义是最后保存的状态，不表示进程仍存活。
- 遇到审批保留 WAITING_APPROVAL，记录 operation ID，继续其他实验；不自动批准、不以人工备注代替授权。
- JSON 保留事件类型/序号、实际审批决定、工具调用数、实际 rag_search 调用数、错误类型及任务 ID。原始执行数据留在本地数据库，摘要不导出模型正文或异常正文。
- 首版不提供评估内的人工诊断续跑界面。事后可追加结构化人工观察，明确标记为操作者备注，与自动执行证据区分；备注不能改变原始成绩、批准请求或恢复任务。

```bash
forgepilot eval-note --workspace /private/tmp/forgepilot-compare-001 \
  --attempt divide_zero-0-on --kind diagnosis \
  --note '检查失败轨迹后发现模型遗漏边界条件；本次结果保留为失败。'
```

kind 支持 diagnosis / approval / cancellation。备注记录时间、脱敏文本与内容摘要；它不是真实审批记录。不要在备注中输入秘密，脱敏无法保证识别所有未知凭据。输出目录必须为专用私有目录；备注有文件锁，报告使用临时文件原子替换并拒绝链接。不要将本地数据库、原始轨迹或含私人备注的报告直接上传。
